# 03 — UI / UX Specification

## Visual direction
Modern, premium, clean, art-first. Avoid cloning Amazon's visual design; copy only its shopping efficiency.

### Suggested palette
- Background: #FFFFFF
- Secondary background: #F7F7F5
- Primary text: #171717
- Secondary text: #666666
- Border: #E5E5E5
- Primary button: #111111 with white text

## Responsive grid
- Wide desktop: 5 product columns
- Desktop: 4
- Tablet: 3
- Mobile: 2

## Header
Desktop: promo bar, logo + large search + account/orders/cart, category nav.
Mobile: menu + logo + wishlist/cart, persistent search beneath.

## Home
1. Hero with ordinary wall art + Custom Canvas CTA.
2. Trust strip.
3. Shop by Category.
4. Best Sellers.
5. Custom Canvas workflow.
6. Shop by Room.
7. New Arrivals / Trending.
8. Reviews / FAQ / Footer.

## Search/category
- Desktop left filter sidebar (240–280px), product grid right.
- Mobile Filter/Sort buttons with bottom-sheet filter panel.

## Product detail
- Desktop: ~60% gallery / 40% sticky purchase panel.
- Mobile: swipe gallery + sticky bottom price/Add to Cart.
- Size shown as buttons.
- Frame shown visually when assets exist.
- Size guide modal.

## Custom Canvas
Explain clearly that the photo is sent to customer service through WS.
Wizard:
1. Size
2. Frame
3. Summary + generated Customization ID + Contact Customer Service

## Cart
Use cart drawer after Add to Cart; full cart page remains available.
Show customization ID on custom products.

## Checkout
One-page checkout, guest checkout supported.
Desktop form left/order summary right; mobile collapsible summary.

## Admin
Efficiency over aesthetics.
Left nav: Dashboard, Products, Import, Categories, Collections, Orders, Custom Orders, Customers, Reviews, Coupons, Staff, Settings, Audit Logs.
Custom Orders should support a workflow board plus detailed timeline/notes.
